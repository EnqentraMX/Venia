Preguntas frecuentes

Familiar¿Cuánto tiempo tarda un divorcio incausado en Monterrey?+

Un divorcio incausado en Monterrey puede tardar entre 2 y 6 meses, dependiendo de si existen hijos, bienes en común o desacuerdos entre las partes. Aunque una persona no esté de acuerdo, el procedimiento puede avanzar legalmente.

Familiar¿Puedo divorciarme aunque mi pareja no quiera?+

Sí. En Nuevo León no se necesita el consentimiento de la otra parte para divorciarse. El divorcio incausado permite iniciar el proceso de forma unilateral.

Familiar¿Qué hago si no me pagan la pensión alimenticia?+

El incumplimiento puede generar embargos, multas y otras medidas legales. Es posible iniciar un procedimiento para exigir el pago y actualizar el monto adeudado.

Civil¿Qué hago si me quieren desalojar?+

Se debe revisar si el desalojo cumple con los requisitos legales. Existen defensas legales para frenar desalojos indebidos.

Mercantil¿Cómo puedo cobrar un pagaré?+

El pagaré permite iniciar un juicio mercantil ejecutivo para exigir el pago de forma más rápida. Incluso pueden decretarse embargos precautorios.

General¿Atienden asuntos urgentes?+

Sí. Algunos casos requieren atención inmediata, como embargos, desalojos o detenciones.
